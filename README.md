# SaaSum AI — Smart Customer Support Chatbot

SaaSum AI is a customer support chatbot built using Python and Streamlit. It uses keyword matching and a predefined FAQ knowledge base to answer common customer questions.

## Features

* Order tracking guidance
* Delivery information
* Payment method information
* Returns and refunds guidance
* Interactive chat interface
* Suggested questions and clear chat option

## Technologies Used

* Python
* Streamlit
* JSON

## How to Run Locally

1. Install Python.

2. Install the required dependency:

   `pip install -r requirements.txt`

3. Run the application:

   `python -m streamlit run app.py`

## Current Limitations

The chatbot provides predefined FAQ-based responses. It does not access live order tracking, process payments, or generate responses using a live AI model.

## Future Scope

* Integrate a generative AI model
* Connect to live order tracking systems
